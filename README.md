# NER Landslide Monitor

An AI early-warning dashboard for landslide risk in Northeast India, built as a single self-contained HTML page (plain HTML, CSS and JavaScript - no build step, no dependencies).

## Features

- Live monitoring dashboard: rainfall (24h), soil moisture, temperature and current risk level
- Environmental trend charts and an AI risk assessment panel
- Live risk map of Northeast India with selectable zones
- Monitored locations including Gangtok and Shillong

## Use

Open `SIH26001_enhanced (2).html` in any browser (double-click it), or serve the folder:

```bash
python3 -m http.server 8000
```
